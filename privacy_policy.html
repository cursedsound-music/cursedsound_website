Privacy Policy

1. Introduction and General Information

The responsible party is Giuseppe Fallea, Schlossbergstraße 2, 76228 Karlsruhe, Germany.

2. Collected Data

Automatically Collected Data

This website is hosted on GitHub Pages. GitHub Pages may log the following technical data:

  • IP address
  • Date and time of access
  • Browser type and operating system
  • Referrer URL
  • Request duration

This data is processed by GitHub according to the GitHub Privacy Statement.

Contact Information

If you contact us via email, we process your email address and other provided information solely to handle your request.

Booking Form

If you send a request via the booking form, we process the information you enter (name, email address and, if provided, promoter / club, event, date, city, country, budget and message) solely to handle your booking or collaboration request. The form data is transmitted over an encrypted connection (HTTPS) via Cloudflare to a server operated by us in Germany, where it is stored in our booking management system. Your IP address is processed briefly to protect the form against spam and abuse (rate limiting) and appears in technical server logs, which are overwritten automatically. No cookies are set by the form.

Spam Protection (Cloudflare Turnstile)

To protect the booking form against automated spam, we use Cloudflare Turnstile, a service of Cloudflare, Inc. Turnstile is only loaded once you start filling in the booking form, not when you simply visit the website. It then connects your browser to Cloudflare, which evaluates technical signals (such as your IP address, browser and device characteristics) to tell people from bots. Our server then checks the result with Cloudflare before accepting your request. Turnstile is not used for advertising or to track you across websites. For details, see the Cloudflare Turnstile Privacy Addendum.

Fonts

The font used on this website is stored together with the website files and delivered by our hosting provider (GitHub Pages) along with the page itself. No connection to external font providers (such as Google Fonts) is established.

No Cookies or External Tracking Tools

Apart from the spam protection on the booking form described above, this website uses no cookies, no external analytics tools (such as Google Analytics), and no external tracking services. No data is collected for advertising purposes. No local or session storage is used to store data on your device.

Purpose Legal Basis

4. Retention Period

Technical Log Data: We have no influence on how long GitHub stores server log data. For details, see the GitHub Privacy Policy.

Email Communication: Your emails are stored as long as necessary to handle your request. After that, they are deleted unless there is a legal retention obligation.

Booking Form: Requests sent via the booking form are stored as long as necessary to handle your request and any resulting booking or collaboration. After that, they are deleted unless there is a legal retention obligation (e.g. for commercial or tax purposes). You can request deletion at any time.
