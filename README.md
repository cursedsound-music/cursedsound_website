# CURSEDSOUND

Official GitHub Pages website for CURSEDSOUND.

## Live Site

https://www.cursedsound.com/

## Stack

- HTML + CSS + vanilla JavaScript
- Hosted on GitHub Pages with custom domain via CNAME
- WebGL hero animation rendered directly on canvas

## Project Structure

- `index.html`: Main landing page (hero, about, contact, booking form)
- `style.css`: Site styling and responsive layout
- `script.js`: Navigation behavior, smooth scrolling, WebGL hero logic
- `legal_notice.html`: Legal notice
- `privacy_policy.html`: Privacy policy
- `CNAME`: GitHub Pages custom domain mapping
- `fonts/`: self-hosted Unbounded (SIL OFL 1.1, license in `fonts/OFL.txt`) — the site makes no third-party requests
- `og-image.png`: 1200×630 link-preview image (WhatsApp, Instagram, Telegram, …)
- `favicon-32.png`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`: browser and home-screen icons
- `robots.txt`, `sitemap.xml`: crawler hints for search engines
